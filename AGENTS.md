# Maintaining this result

The proof, verification code and evidence are maintained in [leecrossley/quadratic-mertens-first-crossings](https://github.com/leecrossley/quadratic-mertens-first-crossings/tree/main/results/yokoi-delay-small-character-correlations). Open issues and pull requests there. Extend this result in its existing directory. For a distinct result in the same family, add a result directory and an entry in the [family index](https://github.com/leecrossley/quadratic-mertens-first-crossings/blob/main/RESULTS.md).

Cite the published versions through the original [GitHub releases](https://github.com/leecrossley/yokoi-delay-small-character-correlations/releases) and [Zenodo DOI](https://doi.org/10.5281/zenodo.24417504). The [research contribution guide](https://github.com/leecrossley/quadratic-mertens-first-crossings/blob/main/AGENTS.md) lists the six maintained families.
